# 주행 중 다음 일정 칩

정책서 6장 '주행 중: 먼저 말하지 않음, 카드 접기 / NextChip'. 주행 중 화면에 남는 유일한 표시로, 창 왼쪽 위에 "다음 13:00 육전집 점심"을 정적인 글자로 보입니다(`DriveSession` → `Effect.ShowNextChip` → `UiState.nextChip` → `ui/NextChip`). main·release 빌드에 모두 있습니다.

## 보이는 조건 (`DriveSession.syncChip`)

모두 만족할 때만 보입니다.

| 조건 | 내용 |
| --- | --- |
| 주행 중 | `Motion.DRIVING`(기어 D·R 또는 주행 제한). 기어를 모르면 아닙니다. |
| 연결됨 | 휴대폰과 연결 전에는 브리핑처럼 칩도 보이지 않습니다. 연결되는 이벤트에서 바로 보입니다. |
| Suspend 아님 | Suspend 중에는 보이지 않고, 돌아오면(`Resumed`) 다시 보입니다. |
| 다음 일정 있음 | `DayPlan.target()`: 도착·건너뜀·종일 일정은 제외합니다. |

## 숨기는 조건

- 정차하면 같은 이벤트 처리에서 바로 숨깁니다(카드와 겹치지 않음).
- 위 조건 중 하나라도 어긋나면(미연결·Suspend·대상 일정 없음) 숨깁니다.
- 일정을 받는 중(`ScheduleLoading`~`ScheduleLoaded`, 탑승 판단 중 다시 받기 포함)에는 칩을 바꾸지 않습니다. 캐시가 이전 기준 시각의 것일 수 있기 때문입니다. 단 정차·미연결·Suspend로 숨기는 것은 받는 중에도 합니다. 받기가 끝나는 이벤트에서 다시 맞춥니다.

## 문구와 모양

- 본문은 `Phrases.nextChipBody`: 24시간제 `HH:mm`(서울 시간대) + 공백 + 제목. 앞에 "다음"이 별도 글자로 붙고 간격은 12입니다.
- 도착하면 다음 일정으로 바뀝니다. 도착 예정은 넣지 않습니다(시안 칩에 없고 도착 시각은 내비 몫).
- 표시 전용: 누를 수 없고 포커스를 받지 않으며 말·소리·애니메이션이 없습니다(주행 규제). 접근성에는 칩 전체의 설명 "다음 13:00 육전집 점심" 하나만 읽힙니다. 긴 제목은 한 줄에서 말줄임합니다.
- 칩 내용이 바뀔 때만 Effect를 냅니다.

## 다시 판단하는 시점

- 모든 이벤트 끝(`flush`)에서 판단합니다.
- 이벤트 없이 시간만 흘러도 맞도록, 칩이 보이는 동안 **대상 일정이 끝나는 시각**(+0.5초)에 `Effect.ScheduleChipRecheck` → `SessionHost`가 토큰과 함께 postDelayed → `Event.ChipRecheck`로 다시 판단합니다(그때 건너뜀이 반영돼 다음 일정으로 바뀝니다). 칩이 바뀌거나 숨겨지면 이전 타이머는 ID가 달라 무시되고, 호스트는 새로 예약하기 전에 이전 것을 지웁니다.
- 기기 시각·시간대가 바뀌거나(`ACTION_TIME_CHANGED`·`ACTION_TIMEZONE_CHANGED`) debug 데모 시계를 움직이면 `Event.ClockChanged`로 예약 시각을 다시 맞춥니다. 이 이벤트는 다른 동작(탑승 판단 등)을 일으키지 않습니다.

## 알려진 한계

- 자정을 넘겨 계속 주행하면 새 날 일정은 다음 탑승·앱 진입 때 받습니다(주행 중에는 일정을 새로 받지 않음).
- 이미 시작한 일정도 끝날 때까지 "다음"으로 보입니다(`DayPlan.target()`이 시작 시각이 아니라 끝 시각 기준).
